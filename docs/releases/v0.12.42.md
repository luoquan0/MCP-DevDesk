# MCP DevDesk v0.12.42

## 修复

- Windows Explorer 重启或任务栏重建后，后台程序仍在运行时托盘图标可能消失：现在监听 Windows `TaskbarCreated` 消息并自动重新添加托盘图标。
- 恢复时保持原来的图标 ID、托盘消息回调、双击打开窗口和右键菜单；若图标未丢失则使用 `NIM_MODIFY` 更新，避免重复添加。
- 修复只涉及桌面托盘生命周期；不重启 MCP Core 或 Cloudflare Tunnel，不改写用户配置、凭据及项目数据。
- 增加 Windows 托盘图标标识与回调参数单元测试。

## 验证与限制

- GitHub Actions Windows CI 已通过 Go 测试、完整构建、NSIS 安装器 smoke test 及 Cloudflare 文件保留检查。
- 正式 Release 仍须再次通过完整 Windows 构建与测试后发布。
- 尚需 Windows 实机在程序运行时重启 `explorer.exe`、检查托盘图标和右键/双击行为；自动测试不能替代数日连续运行验证。
- 如果消失原因是 MCP DevDesk 主进程实际崩溃，此修复不能自动重启已退出的进程；应检查 `data/devdesk/logs/manager.log` 和 Windows 事件查看器。
