# MCP DevDesk v0.12.40

## 修复

- 支持 Google 自定义 MCP 应用动态分配的 `oauth-redirect.googleusercontent.com/r/user_bound_custom-mcp-...` OAuth 回调；保留 HTTPS、回调域名和生成 ID 校验，动态注册客户端继续精确匹配。
- Windows 管理器在清理运行数据与初始化配置之前检查单实例 Mutex，避免第二次启动改写主进程仍在使用的配置文件。
- 托盘消息循环异常结束时通知管理器退出、执行正常关闭，并释放单实例锁，减少“运行多天后打不开”的残留实例风险。
- 当旧进程无法响应托盘与本地管理 API 或启动初始化失败时，Windows 桌面显示明确错误对话框，不再静默失败。
- 加入 Google 回调安全匹配单元测试、单实例配置只读测试及 Windows 单实例 smoke 回归检查。

## 验证说明

正式 Windows Release 必须通过 GitHub Actions 构建和自动测试后才发布。自动回归检查不能替代真实 Windows 机器数日连续运行验证；若问题再现，应结合 `data/devdesk/logs/manager.log` 及 Windows 事件查看器分析。
