# MCP DevDesk v0.12.37

## Fixed

- Fixed the Windows NSIS setup upgrade path overwriting an already updated `cloudflared.exe` with the version bundled in the MCP DevDesk release.
- Setup upgrades now preserve an existing cloudflared runtime; the bundled copy is installed only for a fresh install or when the file is missing.
- Refreshed the bundled recovery/fresh-install cloudflared pin from `2026.8.3` to Cloudflare's `2026.9.1` Windows amd64 release.
- Added an installer regression smoke test that verifies both upgrade preservation and fresh-install seeding.

## Scope

The application-level `devdesk-updater` already preserved an existing cloudflared runtime. This patch closes the remaining NSIS installer overwrite path and does not change Cloudflare tunnel credentials, tunnel configuration, project validation, code navigation, or terminal-session behavior.
