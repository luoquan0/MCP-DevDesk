# MCP DevDesk v0.12.36

## Fixed

- Fixed mojibake in Windows command-session output when legacy console tools emit the system OEM code page (including CP936/GBK on Simplified Chinese Windows).
- Valid UTF-8 output from modern tools remains byte-for-byte unchanged before being returned through `exec_command` / `read_output`.
- Added Windows regression coverage for CP936 Chinese text, UTF-8 Chinese text, and ASCII output.

## Scope

This patch release changes terminal-output decoding only. Project validation, code navigation, Screen Vision, updater behavior, and the v0.12.35 terminal session lifecycle remain unchanged.
