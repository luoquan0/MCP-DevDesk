# MCP DevDesk v0.12.38

## Fixed

- Fixed portable Windows data becoming unusable after reinstalling Windows because `secrets.json` was encrypted only with Current-User DPAPI.
- New secret envelopes use AES-256-GCM with a random portable master key stored at `data/devdesk/master.key`. Backing up or moving the complete `data` directory now keeps MCP/OAuth/Web Control credentials decryptable across a Windows reinstall.
- Existing DPAPI v2 secret envelopes migrate automatically when the old Windows profile can still decrypt them.
- If an old DPAPI envelope can no longer be decrypted after a Windows reinstall, startup now quarantines only that legacy `secrets.json` under `data/devdesk/recovery`, creates fresh credentials, and preserves projects, instances, appearance and other portable settings.
- Fixed portable root discovery so the directory containing `MCP-DevDesk.exe` is preferred over the process current working directory. Shortcuts and shells with a different working directory no longer silently open a different empty `data` tree.
- Added regression coverage for portable secret-directory copies, legacy DPAPI migration/recovery, and executable-directory root selection.

## Important backup note

Starting with v0.12.38, `data/devdesk/master.key` is part of the portable data. Back up the entire `data` directory. Losing `master.key` while keeping an encrypted `secrets.json` makes those credentials unreadable.

## About old PNG/TMP files beside the program

Current Screen Vision capture returns images in memory and does not persist screenshots to the application root. Old `cap-*`, `screen-*`, `restrict-*`, VM/WeChat/music test PNGs and `ssh_pw*.tmp` files seen in historical development folders are test leftovers, not required runtime files. This release does not automatically delete unknown files from the program directory.
