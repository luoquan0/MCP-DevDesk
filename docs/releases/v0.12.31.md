# MCP DevDesk v0.12.31

本版本加入可复用的提示词模板库，并优化长期项目的 Agent 接班方式。

## 新增

- “设置 → 软件设置 → 全局提示词”的“使用通用模板”升级为“使用模板”，点击后打开模板库。
- 内置“持续开发 · 自动接班”和“严格工程 · 发布闭环”两套模板。
- 模板库支持创建、编辑、删除自定义模板，并可一键套用到全局提示词或项目 `AGENTS.md`。
- “项目与运行”的 `AGENTS.md` 编辑窗口增加“使用模板”按钮。

## 长期项目上下文优化

- 内置长期开发模板约定使用项目根目录 `PROJECT_STATUS.md` 保存当前开发状态。
- 状态文件采用覆盖式短摘要，不追加无限历史；建议保持在 6 KiB 内，最多 8 KiB。
- 新会话先利用短摘要恢复当前目标、已完成结果、关键决策、阻塞、下一步和验证结果，再按需读取相关代码与文档，避免为了恢复上下文反复读取大量 Markdown 和完整历史。
- `PROJECT_STATUS.md` 只作为进度缓存，不覆盖用户当前要求或项目 `AGENTS.md` 的规则优先级。

## 验证

- 功能分支 Windows GitHub Actions CI 已通过。
- 合并到 `main` 后 Windows GitHub Actions CI 再次通过完整 `build.ps1 -Arch amd64 -RunTests` 验证。
