# MCP DevDesk v0.12.41

## 修复

- 修复 Google Gemini 自定义 MCP OAuth 授权页的 CSP 表单提交拦截：`form-action` 同时允许配置的 OAuth issuer origin 与已验证的回调 origin，兼容授权页面入口和实际 issuer 不同的部署方式。
- 授权表单改为提交到配置的绝对 `/oauth/authorize` 端点，避免相对路径因页面入口域名不同而提交到错误的 MCP 实例。
- 保留严格 CSP，不开放通配符；issuer 通过 HTTPS/loopback 校验，回调仍通过现有 redirect URI 校验。
- 新增跨域授权页面回归测试，验证 CSP、绝对 POST 目标、授权码生成及携带原始 `state` 跳转到 Google 回调。

## 验证

Windows GitHub Actions 完整 Go 测试、构建和安装器检查通过后方可正式发布。
