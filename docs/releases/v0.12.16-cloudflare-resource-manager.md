# v0.12.16 Cloudflare resource management

This release adds Cloudflare resource management and independent cloudflared updates.

- Cloudflare page lists MCP DevDesk-managed domain/Tunnel bindings.
- Unbind explicitly removes the current DNS record and only deletes the Tunnel when it is not shared by another MCP instance.
- cloudflared can be checked and updated independently from the software update page.
- cloudflared downloads reuse the updater HTTP/SOCKS5 proxy settings and require SHA256 verification.
- Running Tunnel processes are paused for replacement and restored automatically after a successful update.
