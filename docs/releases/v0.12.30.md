# MCP DevDesk v0.12.30

本版本重点修复便携数据导致的启动失败，并完善更新包、日志与恢复备份的自动清理。

## 修复

- 启动前自动检查并恢复损坏的 `config.json`、`appearance.json`、`projects.json`、`instances.json` 与 `update-settings.json`，避免必须手工删除整个 `data` 才能启动。
- DPAPI 代理密码在跨电脑或跨 Windows 用户后无法解密时，仅清空不可恢复的密码字段并保留其他设置，同时保存原配置备份。
- 已保存的主工作目录不存在时，自动回退到程序目录并关闭自动启动，避免启动阶段反复失败。
- 单个独立 MCP 实例配置损坏时自动隔离并重建，不再拖垮主程序。

## 存储与资源清理

- 更新成功并启动新版本后立即删除本次 Portable ZIP。
- 软件启动时清理遗留的 `.zip`、`.tmp`、`.sha256` 更新文件。
- 软件运行期间每 6 小时执行一次轻量维护，仅清理超过 24 小时的更新残留，避免影响正在下载的更新。
- 日志最多保留 100 条，单日志文件与内存缓存上限从 2 MB 调整为 512 KB。
- 超过 14 天未更新的日志自动删除。
- 自动恢复备份最多保留 30 天，每个 recovery 目录最多保留 20 份。
- Windows 临时目录中的 MCP DevDesk Updater 临时文件超过 24 小时自动清理。

## 验证

- 已增加损坏 data 回归测试，故意破坏多类持久化 JSON 后要求应用仍可完成真实初始化。
- 已验证工作目录失效恢复、更新包成功删除/失败保留、周期清理、日志过期清理和 recovery 数量上限。
- Windows amd64 CI 已通过完整 Build/Test 与公开发布敏感信息检查。
