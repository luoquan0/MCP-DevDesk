# MCP DevDesk v0.12.35

`v0.12.35` is a focused stable enhancement release based on the `v0.12.34` stable line.

## Added

- Project validation tools: `validate_project` and `checks_run`.
  - Trusted auto-detection for Go, Node.js, Rust, .NET, Python, and project `build.ps1` workflows.
  - Go validation covers test, vet, and build.
  - Node.js validation only runs declared test/check/typecheck/lint/build scripts and does not guess unknown commands.
- Long-running terminal sessions: `exec_command`, `read_output`, `write_stdin`, and `kill_session`.
  - Long-running builds, tests, development servers, and scripts can be observed and controlled incrementally.
  - Windows process-tree termination is idempotent and avoids duplicate `taskkill` execution.
- Lexical code navigation: `document_symbols`, `workspace_symbols`, `find_definition`, and `find_references`.
  - Uses the proven static lexical fallback implementation; no persistent LSP is introduced in this release.

## Verification

The Windows release pipeline runs frontend production build, `gofmt` verification, `go test -mod=vendor ./...`, full Windows amd64 builds, existing MCP core smoke tests, v0.12.35 compiled-core JSON-RPC smoke tests, real terminal session lifecycle checks, and portable-package verification before publishing.

## Intentionally not included

This release does **not** include the v0.13 experimental AI Workspace stack: Agent Tasks, `task_*` tools, task heartbeat/persistence, task/job bindings, automatic Git Worktree isolation, Accept/Reject review flows, Agent Tasks UI, persistent LSP, or the v0.13 Screen Vision experiments. Existing stable Screen Vision behavior is unchanged.
