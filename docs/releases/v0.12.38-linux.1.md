# MCP DevDesk Linux Server v0.12.38-linux.1

First Linux preview, branched cleanly from stable `v0.12.37` on `feature/linux-server`. Windows `main`, its stable Release and its update channel are not replaced.

## Downloads

- `MCP-DevDesk-Linux-amd64.tar.gz`: native x86-64 Intel/AMD Linux.
- `MCP-DevDesk-Linux-arm64.tar.gz`: native AArch64 Linux.
- Each archive has a `.sha256` file, an internal `SHA256SUMS`, and an architecture-specific build evidence manifest attached to this Release.

## Start

Extract the correct architecture package into a new directory, then run:

```bash
./mcp-devdesk --init --lan
./mcp-devdesk
```

Save the generated web password. Open `http://PRIVATE_LINUX_IP:17861/` and sign in. For an Internet server, initialize without `--lan` and access port 17861 through SSH forwarding rather than exposing a management API publicly. Optional background service: `./install-service.sh` as the normal project-owning user.

## Included

- Headless Linux manager with the same embedded Vue Web Control and management APIs.
- Native Go MCP Core, CLI and SHA256-verified Linux cloudflared runtime.
- Password-protected Web Control by default; AES-256-GCM encrypted secrets with an owner-only master key.
- Project validation, long-running terminal sessions with Linux process-group termination, and lexical code navigation from the stable line.
- Native TCP listener ownership, tunnel process inventory and Linux cloudflared asset selection.
- A manual Linux upgrade helper that preserves data, the master key and an existing cloudflared runtime.

## Boundaries

This is a **prerelease**, not a production support guarantee. Native Ubuntu amd64/arm64 acceptance tests and the Windows regression gate must pass before publication. No Windows desktop/WebView2/tray, Windows legacy core, Linux Screen Vision, persistent LSP or 0.13 AI Task architecture is added. Linux automatic in-app binary installation is not enabled in this preview; use the documented stopped-service upgrade helper. Cloudflare account authorization and actual public-domain tunnel operation still require the user's credentials and deployment environment and are not exercised against a live account by CI.

Read the included `README.md` / `docs/LINUX.md` for setup, password recovery, key backup, systemd and upgrades. The packages are **not independently signed**; SHA256 checksums are supplied for integrity verification.
