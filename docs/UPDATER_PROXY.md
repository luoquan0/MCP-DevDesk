# 软件更新代理

MCP DevDesk 的软件更新代理只影响 GitHub Releases 版本检查、SHA256 获取和更新包下载，不影响 MCP Core、Cloudflare Tunnel 或项目网络访问。

设置时只需要填写代理 IP/主机名和端口。程序会自动尝试 HTTP CONNECT 与无认证 SOCKS5，并缓存本次运行中识别成功的协议。常见本地端口如 7890、1080、10808 都可以通过“测试代理”确认。

“测试代理”会访问 GitHub，成功时显示识别出的协议和延迟；失败时分别显示 HTTP 与 SOCKS5 的错误。测试和检查更新都使用短连接超时，错误代理不会长时间锁住更新页面。
