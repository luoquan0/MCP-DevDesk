# 软件更新代理

MCP DevDesk 的更新代理只影响 GitHub Releases 版本检查、SHA256 获取和更新包下载，不影响 MCP Core、Cloudflare Tunnel 或项目联网。

## 配置

只填写代理 IP/主机名和端口，例如：

```text
127.0.0.1
10808
```

程序会先进行不超过约 1.2 秒的本地代理协议探测，再使用 HTTP CONNECT 或无认证 SOCKS5。代理端口不可达时会快速失败，不再通过两套长网络请求串行试错。

保存代理后界面会提示“已使用代理模式”。点击“测试代理”会验证 GitHub API 连通性，并显示最终使用的 HTTP / SOCKS5 协议和耗时。

## 超时原则

- 本地代理协议探测：短超时，避免 UI 看起来卡死。
- 代理响应头：独立短超时。
- 更新包主体：仍支持长时间流式下载、自动重试、断点续传和 SHA256 校验。
- 若探测出的协议请求失败，会在有界超时内尝试另一种协议并缓存最终成功的模式。
